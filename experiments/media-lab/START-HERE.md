## Recording conventions

Copy `run-template.json` to `runs/<run-id>.json`. Use ISO 8601 timestamps with timezone and seconds for duration fields. Statuses: planned, running, completed, blocked, rejected, deferred. A run can be completed offline with every publication field null. Null is unknown/unmeasured; explain it in `missing_data_reasons`. Use `review.not_applicable` for dimensions genuinely absent from that format.

Use a separate run record for each platform adaptation, sharing `family_id` and linking `parent_run_id` where appropriate. Reusing an image or changing aspect ratio does not create a new independent experiment. Record native format, musical treatment and topic-place label/tag separately. `destinations.json` is a discovery template: null identities are not configured publishing targets.

Each timing stage should record name, start/end, active seconds and whether it overlaps another stage. Each attempt should record its number, settings/prompt location, outcome, elapsed time, spend and artifact paths. Each artifact should record path, SHA-256, media type, dimensions, duration where applicable, source/license and whether it is the original or a derivative. Never store credentials.

Each publication snapshot should record observation timestamp, post age, raw platform metric names/values, denominators for derived rates and missing-metric reasons. `cost.incremental_spend` becomes 0 only after confirming no new charge occurred. Composite scores and elapsed totals should be calculated from the recorded evidence, not guessed.
